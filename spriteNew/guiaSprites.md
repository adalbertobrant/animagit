# Guia de sprites 

### Personagem principal do jogo
1. sprite-001.jpg -> personagem ação inicial
2. sprite-002.jpg -> personagem realizando o git add.
3. sprite-003.jpg -> personagem avançando para o git commit.
4. sprite-004.jpg -> personagem fazendo o git push.
5. sprite-005.jpg -> personagem após o git push
6. sprite-006.jpg -> personagem correndo
7. sprite-007.jpg -> personagem saltando
8. sprite-008.jpg -> personagem ganhando e chegando ao final

### Personagem quadrado do pull request, esse personagem intera com o personagem principal
seus sprites são:
sprite-pr-001.jpg até o sprite-pr-009.jpg

### Personagem fixo no ínicio da tela 
sprite-start.jpg -> aparece no início do jogo do lado superior do personagem é o ponto de start(início do jogo)

### Personagem fixo no fim da tela lado direito
sprite-end.jpg -> o personagem cruza esse sprite alcançando os seus objetivos

### personagem coração que mostra no canto superior esquero da tela
são corações mostrando a vida do personagem , e caso ele sofra dano mostra um coração mais escuro
sprite-heart-full.jpg -> coração de ponto de vida sem dano
sprite-heart-dead.jpg -> mostra quando não tem mais vidas para o jogador

### estrelas
O personagem principal vai colhendo as estrelas que aparecem ao logo do caminho
sprite-star-3.jpg -> indica uma estrela grande, aparece poucas vezes
sprite-star-2.jpg -> aparece mais 
sprite-star-1.jpg -> mostra quando outra estrela vai aparecer

### códigos
O personagem vai coletando os códigos, após a coleta de 5 códigos ele tem que fazer os passos git add, git commit e git push
sprite-code-001.jpg -> código 
sprite-code-002.jpg -> código final
sprite-code-003.jpg -> outro código
Esses códigos aparecem para o personagem ele tem a opção de coletar ou pular eles.
São pull requests de outras pessoas, se ele coletar deve após 5 códigos tomar os passos já explicados

### fundo 
sprite-montain.jpg fica acima da tela onde ocorre a ação do personagem é o fundo

### castelo e torre
sprite-tower.jpg e sprite-castle.jpg -> ficam na parte do sprite end e é onde o personagem entra.

### campo
sprite-field.jpg -> é onde o personagem anda, são compostos vários fields um do lado do outro para que o personagem possa andar 
é no campo onde vai ocorrer a ação do jogo.
